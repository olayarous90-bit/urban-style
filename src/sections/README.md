# Arquitectura de Secciones - URBAN STYLE

Este directorio albergará los componentes de sección que compondrán la landing page en las siguientes etapas.

## Plan de Secciones a Integrar Progresivamente:

1. **Barra de Anuncios (`AnnouncementBar`)**:
   - Mensajes promocionales rotativos (ej. envíos gratis, ofertas de temporada).
2. **Navegación (`Navbar`)**:
   - Logotipo de URBAN STYLE, enlaces a categorías principales, buscador y acceso rápido.
3. **Portada Principal (`Hero`)**:
   - Titular de alto impacto con el eslogan *"TU ESTILO. TUS REGLAS."*, llamada a la acción y estética urbana.
4. **Categorías (`Categories`)**:
   - Accesos directos a: Ropa para hombre, Ropa para mujer, Zapatillas y Accesorios.
5. **Productos Destacados (`FeaturedProducts`)**:
   - Tarjetas de producto con precios, badges de novedades y acciones rápidas.
6. **Colecciones (`Collections`)**:
   - Lookbooks y colecciones cápsula de temporada.
7. **Ofertas y Promociones (`Promotions`)**:
   - Banners con descuentos especiales y cuenta regresiva.
8. **Información de Marca (`BrandStory` / `Features`)**:
   - Valores de la marca, compromiso de calidad, política de envíos y autenticidad urbana.
9. **Formulario de Novedades (`Newsletter`)**:
   - Captura de suscriptores para lanzamientos exclusivos y descuentos.
10. **Pie de Página (`Footer`)**:
    - Enlaces institucionales, redes sociales, métodos de pago y créditos.
